# Images Folder

This folder is for storing your portfolio images.

## How to add your profile image:

1. Save your profile photo as `alexandra.jpg` (or `.png`) in this folder
2. Make sure the image is:
   - Square format (350x350 pixels recommended)
   - High quality but compressed for web
   - Under 1MB file size

## Current image references in the website:

- **Profile Image**: `images/alexandra.jpg` (used in index.html hero section)
- You can also add more images for:
  - Instagram posts
  - Portfolio carousel images
  - Project screenshots
  - Any other images you want to use

## Supported formats:
- JPG/JPEG
- PNG
- WebP

## Tips:
- Keep file names simple and lowercase
- Use descriptive names like `profile.jpg`, `project1.png`, etc.
- Optimize images for web to ensure fast loading
