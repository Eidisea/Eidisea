# Eidisea Portfolio

A personal portfolio website showcasing my work and projects.

## Features

- Home page with introduction
- About page with personal information
- Login and registration functionality
- Responsive design
- Image gallery

## Files Structure

- `portfolio/index.html` - Main homepage
- `portfolio/about.html` - About page
- `portfolio/login.html` - Login page
- `portfolio/register.html` - Registration page
- `portfolio/style.css` - Stylesheet
- `portfolio/images/` - Image assets

## Getting Started

Open `portfolio/index.html` in your web browser to view the website.

## Technologies Used

- HTML5
- CSS3
- Responsive Web Design
